Chess ELO Bot – Privacy Policy

Last updated: November 24, 2026

Data collected

Chess ELO Bot stores:

Discord user ID

Chess.com username

Public Chess.com rating statistics

Rating history and update timestamps

Purpose of data collection

This data is used exclusively to:

Connect Discord users with Chess.com accounts.

Display personal statistics.

Generate leaderboards.

Maintain rating history.

Data storage

Data is stored in an SQLite database maintained by the bot operator.

Data sharing

The bot does not intentionally sell or share stored account links with third parties.

Chess.com public API is used to retrieve public player statistics.

Removing data

Users can disconnect their Chess.com account using !unconnect.

Contact

Contact the bot operator through the Discord server where the bot is used.
